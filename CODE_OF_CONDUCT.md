# Code of conduct

This project follows the [Rust Code of Conduct](https://www.rust-lang.org/policies/code-of-conduct).

In short: be respectful, assume good faith, and criticise ideas rather than people. Technical
disagreement is the work; contempt is not.

## Two things specific to this project

**Findings about other people's software are handled carefully.** When Bohr finds a bug in a
third-party project, we report it privately to the maintainers first, wait for a fix, and publish
afterwards. We do not use someone else's defect as marketing material before they have had the
chance to address it. This is the Jepsen order, and it is the reason Jepsen is welcomed rather than
resented. It applies to everyone using this repository, not only to the maintainers.

**A bug report is not an accusation.** Maintainers of the projects we hunt in are colleagues. Reports
are written as "here is what we found and how to reproduce it", never as a judgement about the
quality of their work. Distributed systems are hard; that is the entire premise of this tool.

## Reporting

Conduct concerns: open a private report through GitHub (**Security → Report a vulnerability**) or contact a maintainer directly. Reports are handled confidentially. If a report concerns a
maintainer, it can be sent to any other maintainer directly.
